# common

Код, который переиспользуется больше чем одним RQ-направлением (например,
загрузка AEGIS/WildGuardMix, general-purpose эмбеддинг-обёртки над моделями).

Пока пусто — переносить сюда код только когда он реально понадобится в
двух и более `rqN_*` каталогах, чтобы не плодить абстракции заранее. Например
`rq4_training_pairs/src/data/sources.py` — кандидат на переезд сюда, если RQ1
тоже начнёт грузить AEGIS программно (а не только через Colab).
